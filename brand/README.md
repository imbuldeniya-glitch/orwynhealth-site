# Orwyn logo, master vector

This folder exists so the Orwyn logo is under version control and off this machine. It is a
copy; the working copy lives in `Orwyn Ltd/04-brand/master-vector/`, with the full note.

`orwyn-logo-master.svg` is the single source for every Orwyn logo asset. Never regenerate a
logo from a PNG. Derive from this file.

- `orwyn-logo-master.svg` — the master: full square, plum ground, white and coral figure.
- `orwyn-mark-transparent.svg` — figure only, transparent, full colour. The website hero
  inlines this.
- `orwyn-mark-mono-white.svg` — figure in white, for dark grounds and one-colour print.
- `orwyn-mark-mono-plum.svg` — figure in plum, for light grounds and one-colour print.

Colours: plum `#2B1B2E`, coral `#E5735B`, white `#FFFFFF`, matching `:root` in `styles.css`.

Trade mark: Orwyn, UK00004424413, applicant Orwynhealth Ltd (17374862). The logo is a separate
later filing awaiting final artwork, which is one of the reasons a clean vector matters.

These files are served by Vercel and cost nothing there, but nothing on the site links to them,
so they will not be crawled or indexed.
